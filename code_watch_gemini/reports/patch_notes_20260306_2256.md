## TL;DR

This release focuses on improving the user experience for Telegram with streaming messages and table rendering, while also delivering a large number of fixes and enhancements for the Feishu channel. Core updates include lazy-loading providers for better performance, multi-instance support for the gateway, and improved stability.

## Themes

*   **Telegram Channel Enhancements**: The user experience in Telegram has been significantly improved with the implementation of draft/progress streaming messages and support for rendering tables.
*   **Feishu Channel Fixes**: A series of fixes for Feishu improve its reliability and functionality, including smart message format selection, proper handling of mp4 video files, splitting card messages with multiple tables, and isolating the WebSocket client event loop.
*   **Core System & Performance Improvements**: The application is now more performant due to the lazy-loading of provider dependencies. The gateway can run multiple instances using new `--workspace` and `--config` options. Stability is improved with better signal handling, including Windows compatibility. Other core fixes include more reliable image MIME type detection and correct handling of list-type tool call arguments.
*   **New Integrations & Features**: Support has been added for SSE (Server-Sent Events) transport with auto-detection. Custom providers can now use a session affinity header for better cache locality. The Discord channel now has a group policy to control group response behavior.
